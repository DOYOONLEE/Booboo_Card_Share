# Booboo Card Share

삼성 메시지의 삼성카드 RCS 승인·취소 내역을 선택 기간별로 불러와 분류하고, 가족 두 명이 비공개 웹 리포트에서 함께 정리하는 Android 앱입니다.

## 주요 기능

- 삼성카드 승인안내 RCS 대화 자동 스크롤 수집
- 시작일·종료일 기준 조회와 중복 제거
- 외식, 쇼핑, 쿠팡, 배달, 기타, 공과금, 제외 분류
- 총 카드값, 제외금액, 실제 카드값 계산
- 대시보드, 카테고리별 목록, 날짜별 캘린더 3개 탭
- 하단 탭 선택 및 좌우 스와이프 탐색
- 분류와 직접 수정한 금액을 기기에 저장
- 같은 가맹점의 분류 자동 적용
- 2인 전용 서버로 선택 기간 리포트 동기화
- 웹에서 수정한 분류를 Android 앱으로 반영

RCS 내역은 Android 공개 메시지 API로 직접 읽을 수 없어 접근성 서비스를 사용합니다. 사용자가 불러오기를 실행한 동안 삼성 메시지의 `삼성카드 승인안내(1588-8900)` 대화만 읽고 스크롤하며, 메시지를 전송하거나 삭제하지 않습니다. 서버에는 RCS 원문을 보내지 않고 날짜·가맹점·금액·취소 상태·분류만 전송합니다.

가족 공유 서버의 설치와 계정 생성 방법은 [`server/README.md`](server/README.md)에 있습니다.

## 빌드

JDK 17, Android SDK 35가 필요합니다.

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다.

## 검증

- Android 단위 테스트 13개 및 서버 통합 테스트 통과
- SM-F971N 실기기에서 2026-09-01~09-30 RCS 146건 수집 확인
- 금액 파싱, 기간 필터, 중복 제거, 분류 저장 확인
